# 最后防线 · 全面反击

纯静态浏览器 Canvas 生存射击游戏，支持桌面和手机，无需后端、数据库或外部游戏资源。

在线游玩：[last-line-total-counterattack.lovable.app](https://last-line-total-counterattack.lovable.app)

Lovable 项目：[最后防线 · 全面反击](https://lovable.dev/projects/b83ae7fa-fea4-4af6-a33f-d5f410d2d26d)。线上原样托管的游戏文件路径为 `public/game/index.html`，首页全视口加载该游戏。

Lovable 首页宿主源码备份在 `hosting/lovable-route.tsx`，对应远程 `src/routes/index.tsx`。页面通过持续生效的 CSS 隐藏 `#lovable-badge`，刷新及延迟注入时均无需手动关闭，同时不再为徽标预留底部空间。此处理属于页面显示规则，没有更改账号套餐或付费发布设置。

## 游玩

直接打开 `index.html`，或运行 `npm run serve` 后访问 `http://localhost:8080`。

提供 30 波战役、无限波次和无尽生存。无尽生存可选择普通模式或全武器模式。

全武器模式同时部署十二件武器，尸潮生成数量和容纳上限为普通生存的 10 倍，生命、攻击、移速按 1.5 倍时间推进成长曲线。经验获取减少 60%，保留原来的 40%。

每 50 次击杀、每 90 秒生存以及每次灾变巨尸击破：普通生存获得一次强化；全武器模式获得 40 经验，100 经验兑换一次强化，未兑换的经验随存档保留。金币和技能充能保持原规则。

所有模式的武器在有效等级达到 5 级时自动获得原有的范围／弹道进化，20 级时再自动叠加原有的伤害进化。两次效果同时保留，无需选择或点击。旧存档按当前等级自动补齐进化，保留等级和资源；战术整备中可查看两个阶段的效果及生效状态。

## 操作

- 自动射击；拖动战场手动瞄准，松手自动锁敌。
- 点击武器卡，或按 Q / W / E 释放当前页武器技能。
- 全武器模式按 A / D 或点击箭头切换技能页。
- 全武器模式点击“一键释放”或按 F 释放所有已就绪、未在施放中的武器技能；无敌人时不消耗充能。
- 空格释放超载；R 部署城防护盾；T 打开或关闭无尽生存战术整备；Esc 暂停或返回战斗。
- 战术整备可向下滚动查看全部武器改装、进化和伤害统计。

## 开发与验证

主源码是 `最后防线_全面反击_v2-8.html`。编辑后运行 `npm run build` 同步生成静态入口 `index.html`。

```sh
npm run build
npm test
```

无需安装 npm 依赖。测试覆盖全部武器、10 倍出兵及上限、1.5 倍强度成长、一键释放、40% 经验积累、5/20 级自动进化叠加、弹道和范围效果，以及新旧存档恢复。

存档使用浏览器 localStorage；不同域名和浏览器的存档分别保存。
